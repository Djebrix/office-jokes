One line about office life, under 200 characters, written to `/output/entry.txt` by a small deterministic Python program. See the competition at https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a.

## Run

```sh
python3 main.py
```

This writes the joke to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
